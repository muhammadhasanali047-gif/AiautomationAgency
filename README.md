# NexaCore Automations

**AI Automation & Full-Stack Development Agency**

NexaCore Automations is a premium software engineering agency specializing in end-to-end intelligent systems. We bridge generative AI, autonomous agent workflows, enterprise email marketing infrastructures, and scalable full-stack web applications for modern businesses.

### Core Services

* AI Automation
* AI Chatbots
* WhatsApp Automation
* Email Marketing
* Full-Stack Development

### Technology Stack

* **Framework:** Next.js 14 (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS, Framer Motion
* **Database & Auth:** Supabase (PostgreSQL, RLS)
* **AI Integration:** Google Gemini API
* **Email Infrastructure:** Resend

### Development

To run this project locally, ensure you have Node.js installed, then execute the following commands:

\\\ash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build

# Start the production server
npm run start
\\\

> **Note:** You must configure the environment variables provided in \.env.example\ for the AI Assistant and Supabase integrations to function locally.
